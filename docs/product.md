# Product brief

This is a planned third-party Spotify app for socializing around music. Users should be able to browse what other users are currently listening to, jam together, or join a room. A customizable character is planned for a later stage. The project name is undecided.

This is the confirmed product direction, not an MVP specification. The first user journey, what "jam together" means in the product, room behavior, how listening activity is shared, privacy choices, Spotify integration requirements, and character customization details remain undecided. The preparation brief also mentions discovery, messages, profiles, PostgreSQL, Drizzle, and 3D client libraries; those references do not approve particular features or technical behavior.

The current UI and `/hello` API are BHVR starter examples. They do not implement the product direction.

Before a feature begins, record its audience, user goal, selected behavior, data ownership, failure cases, and acceptance criteria here or in a linked feature brief. Keep undecided details marked as undecided rather than filling them with assumptions.
